# Launchpad — Opportunity Management App

A browser-based web app for organizing job opportunities and applications.

## Features
- Add, edit and filter opportunities
- Search applications and manage deadlines
- Export CSV and backup/restore JSON
- Store information locally in the browser

## Run locally
Open `index.html` in a modern browser. No installation needed.

## Public demonstration
This is a front-end-only project. No account, server, or cloud database is used. Your data is stored in your browser.

## Technologies
HTML5, CSS3, JavaScript, localStorage.
