## Windows CMD — update and run

Back up important workspaces with JSON first. Keep any local code changes; do not use `reset --hard`.

```bat
cd launchpad-career
git status
git fetch origin
git switch feat/launchpad-5.9-public-beta
git pull --ff-only
set PUBLIC_SUPABASE_URL=
set PUBLIC_PUBLISHABLE_KEY=
set REQUIRE_PUBLIC_AUTH_CONFIG=
npm ci
npx playwright install chromium
npm run build
npm run build:check
npm test
npm run audit:public
npm start
```

If the branch is not yet local, use `git switch --track origin/feat/launchpad-5.9-public-beta` after fetch. With Node 24 installed, `npm start` serves the source locally at `http://127.0.0.1:8000/#home`. Ctrl+C stops it. This is a local preview, not a public deployment or proof of live Auth.

These `set ...=` commands affect this CMD session only; they do not erase remote configuration. The committed Auth configuration remains blank by default. Do not commit a private key or personal session token.
