# Launchpad 5.1 illustration and company assets

`assets/career-ascent.svg` is an original vector illustration created for Launchpad
in this task. It does not reproduce a third-party product illustration. Existing
Launchpad logo artwork is preserved unchanged. No reference screenshots were
included with the request; the written direction informed the design.

Seventeen decorative company marks are locally vendored from **Simple Icons
16.36.0**, package license CC0-1.0, with its full license at
`assets/companies/LICENSE.md`. Package integrity:

```

```

Source: https://www.npmjs.com/package/simple-icons/v/16.36.0 . The mapping is
explicit in `data/company-marks.mjs`; exact curated names/IDs/websites are used.
Custom/mismatching directory identities receive a neutral building glyph.
Applications/provider results can match an exact catalog name for a decorative
mark; this does not independently verify the employer or the vacancy.

Simple Icons is an independently maintained library, not an endorsement or a
blanket trademark permission. The SVGs are not described as official/approved
by the named companies. Marks are rendered unmodified in black on white for
readability; companies absent from the pinned library retain the neutral fallback
rather than a guessed mark. Operator review of individual brand guidelines and
applicable trademark permissions remains necessary before commercial release.
No remote logo service receives the user's company searches or browsing activity.

Reproduction: download the exact package using `npm pack simple-icons@16.36.0`,
verify the integrity above, and copy only the matching listed `icons/<id>.svg`
files and LICENSE.md. Review changes before replacing assets. The package is
not added to the production dependency tree or shipped wholesale.
