# Launchpad 5.1 — 60–90 second product walkthrough

Use the reviewed local build or an approved staging deployment. Start in a clean
guest browser profile or an authorized test account; never display real customer
PII, mailbox links, tokens, receipts, payment details or API configuration on video.
Screenshots in this repository use a clean local workspace with real empty states.

- **0–12 seconds — Discover:** open `#home`. “Launchpad brings opportunities,
  employer research and a practical learning plan into one career workspace.”
  Show the original logo/illustration and authentic product preview. No invented
  adoption, salary, employment or customer-success claims.
- **12–30 seconds — Dashboard:** open `#dashboard`. Explain the personal progress
  ring, actual-record metrics, recent applications, next task and coach entry.
  Empty counts mean no activity in the current workspace, not missing demo data.
- **30–45 seconds — Applications:** add a clearly labeled demonstration employer
  record, review its fields, switch to Kanban and move using the keyboard-accessible
  stage selector. Show save feedback and JSON export. Never imply a test record is
  an actual vacancy. Remove the demonstration only from the test workspace.
- **45–58 seconds — Companies and roadmap:** search Google, switch grid/list,
  favorite it, then show a personal goal and editable milestones. Marks identify
  employers, not hiring or affiliation. Starter roadmaps are editable templates,
  not claimed AI responses.
- **58–73 seconds — Coach and jobs:** show prompt suggestions and consent choices.
  If the backend is unavailable, show that state explicitly. Only display actual
  sourced jobs or actual provider-generated responses when configured and tested.
- **73–90 seconds — Account and plans:** show the polished account dialog,
  proposed USD plans and cancellation/renewal FAQ. Explain that protected cloud
  mutations and AI usage are enforced by the server. Do not demonstrate a real
  purchase unless an approved Sandbox account and receipt test are available.

Close with “A release candidate for controlled acceptance; public commercial
activation depends on verified email, Sandbox lifecycle and deployment checks.”
The [staging runbook](5.1-STAGING.md) separates implemented flows from external
activation gates. The [screenshot comparison](../screenshots/5.1/README.md) supports
portfolio/recruiter review without inventing customers or integrations.
